# ⚡ NEGRET'S BOT

AutoResponder da NEGRET'S - Assistência Técnica Barueri/SP

## Como funciona?
Cliente manda mensagem no WhatsApp -> Bot lê a notificação -> Responde sozinho com preço, rastreio e horário.

## Como usar?
1. Baixe o projeto
2. Abra no Android Studio
3. Ative a permissão de Notificação
4. Pronto!

## Variáveis
{nome} {preco} {codigo} {status}

## Regras
- oi -> Boas-vindas
- preco -> Tabela de preços
- rastreio -> Pede código NEG-xxxx
